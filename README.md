# MAMOUSCA

Personal portfolio of Diogo, a Design and Multimedia graduate from the University of Coimbra. The website showcases a selection of projects developed during his Bachelor's degree, along with information about him and ways to get in touch.

Built with plain HTML, CSS and JavaScript, with no third-party libraries, for the Web Development course (MDM, University of Coimbra).

**Live site:** https://1pacotedeskittles.github.io/website_assignment_2_DW/

## Requirements covered

- **Dynamic interaction:** custom cursor (a fly that follows the mouse), clickable "Wow!" animation, project dialog with an image slider.
- **CSS animation:** pulsing and colour-cycling title on the home page, hover overlays and page transitions.
- **Generated content:** the projects are loaded from `projects.json` with `fetch` and rendered by JavaScript.
- **Responsive:** fluid grids and media queries for tablets and mobile.
- **No third-party libraries.**
